# KJMJFAH - Teams Calendar & Time Tracker

A modern Teams calendar application that helps product teams organize time-off and track bug fixing time. Features a beautiful pixel-art themed onboarding experience with animated backgrounds and modern UI design.

## Features

### 🎨 Modern Onboarding Experience
- Beautiful pixel-art team background
- Animated gradient orbs
- Modern glassmorphism design
- Smooth animations and transitions
- Excellent contrast and accessibility

### 📅 Calendar & Time-Off Tracking
- Visual calendar view showing team member availability
- Add time-off entries with dates and reasons
- Automatic sprint number detection (2-week sprints)
- Sprint information displayed on calendar dates
- Team member time-off visible on calendar

### 🐛 Bug Time Tracker
- Start/stop timer for bug fixes
- Track time spent on specific bug numbers
- View history of bug time entries
- Total time calculation per team member

### 🎯 Sprint Planning Integration
- View current and upcoming sprints
- See all team members out during each sprint
- Automatic sprint date calculation
- Time-off automatically reflected in sprint planning

### Development

```bash

```

### Build

```bash
npm run build
```

## Usage

1. **Add Time Off**: Click on any date in the calendar to add a time-off entry
2. **Track Bugs**: Select a team member, enter bug number, and start the timer
3. **View Sprints**: Check the Sprint View tab to see time-off scheduled for current and upcoming sprints
4. **Update Profile**: Go to the Profile tab to select and update your country and location
